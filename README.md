🚀 AI-Driven Personalized Marketing Platform
📌 Project Overview

The AI-Driven Personalized Marketing Platform is a web-based application designed to automate and personalize digital marketing campaigns. The system delivers targeted product recommendations and marketing messages to users based on their preferences and behavior. It also provides role-based access for administrators and users to manage products and campaigns efficiently.

🎯 Objectives

To provide personalized product recommendations to users

To automate marketing campaigns through scheduling

To implement role-based access control (Admin & User)
